PDFNova (browser-only version)
==============================
Static website. No server, no database, no login. Every PDF is processed
inside the visitor's browser, so files never leave their phone or PC.

Deploy
------
Netlify (easiest): app.netlify.com -> Add new site -> Deploy manually ->
drag the whole folder (the one containing index.html) into the box.

GitHub Pages: create a repository, upload all files, then
Settings -> Pages -> Deploy from branch -> main / (root).

Tools included: Merge, Split, Remove pages, Extract pages, Organize, Rotate,
Crop, Page numbers, Watermark, JPG to PDF, PDF to JPG, PDF to Text,
Compress, Unlock, Edit & Sign PDF (edit.html).

Not possible in a browser-only site: Word/Excel/PowerPoint to PDF, OCR,
password protect. Those need the full PDFNova server app.
